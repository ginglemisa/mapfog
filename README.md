# MapFog

免安裝的繁體中文 TRPG 地圖、戰爭迷霧、Token 與先攻管理工具。GM 與玩家有各自的瀏覽器畫面。

## 使用方式

在本機啟動靜態網站伺服器（瀏覽器直接開啟 `file://` 可能讓某些功能失效）：

```sh
python -m http.server 8765
```

開啟 `http://localhost:8765/`，再選擇 GM 或玩家入口。在 Windows 上也可執行 `start-server.bat`。

- `gm.html`：GM 控制台
- `player.html`：玩家畫面
- `?room=房間名`：支援同步服務時，共用的遠端房間代號（見首頁說明）
- `?olroom=房間名`：本機分房暫存；並非不同裝置間的連線方式

GM 可將先攻表中的名字拖曳到地圖上，建立友方綠底或敵方紅底的白字 token，顯示名稱中第一個英文或中文字元；首字重複時，依序在圖上加上編號，例如「哥、哥1、哥2」。Token 清單則保留完整角色名稱。點擊名字（或以鍵盤 Enter／空白鍵啟用）則放在地圖中央。新 token 可沿用 Token 面板調整大小、形狀與刪除，並同步到玩家畫面；拖曳列上的順位數字仍可調整先攻順序。無論是上傳圖片或由先攻表建立的 token，在 GM 與玩家畫面旋轉地圖時都維持原本方向。

## iPad UI 第一版

iPad 或其他帶觸控螢幕、寬度至少 680 CSS px 的裝置，GM 頁面會啟用平板操作布局：

- 地圖設定預設收起，使用右下角「地圖設定」按鈕開啟。
- 格線、Token、先攻、擲骰與地圖設定同時間只保留一個控制面板。
- 先攻管理變成右側固定抽屜，不再需要用手指拖動浮動視窗。
- 地圖主要工具列可橫向滑動，按鈕保留觸控尺寸。
- 點擊地圖或按 Esc 可以收起面板。
- 非觸控桌面版維持原有布局和可移動先攻視窗。

**尚未完成：** 複雜的雙指觸控／畫霧衝突解決、大圖 Canvas 降記憶體，以及實機 iPad Safari 測試。

## 部署與安全

這個專案是純前端靜態網站；若自行部署並啟用 Firebase 同步，請先檢查資料庫規則與房間存取權限。前端 Firebase `apiKey` 並不等同私密伺服器金鑰，也不能取代資料庫安全規則。
