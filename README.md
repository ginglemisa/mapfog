# MapFog

**線上使用：<https://mapfog.ginglemisa.workers.dev/>**

跑團用的戰爭迷霧地圖。GM 上傳地圖、一點一點擦開迷霧，玩家在自己的畫面看到被打開的區域，還可以放棋子（Token）、排先攻、擲骰。免安裝，用瀏覽器打開就能用。

## 先決定怎麼玩

打開網址後按「**GM 控制台**」，會問你要用哪一種方式：

| 你的情況 | 選這個 | 玩家怎麼看 |
|---|---|---|
| 一台電腦，接第二個螢幕或投影給玩家看 | **快速使用** | 同一台電腦、同一個瀏覽器再開一個「玩家畫面」視窗，拖到第二個螢幕 |
| 同上，但想替每張地圖分開存 | **單機分房** | 同上 |
| 大家用自己的手機、平板或電腦 | **跨裝置（網路）** | 掃 GM 畫面上的「玩家 QR Code」 |
| 沒有網路，只有 Wi-Fi 分享器或手機熱點 | **區域網路** | 需要先在 GM 筆電安裝程式，見最下方 |

- 「跨裝置」的房間名稱要 **8–10 個字**，只能用英文字母、數字和 `-`，例如 `mygame01`。GM 和玩家必須用同一個名稱。
- 同一台電腦上，GM 和玩家視窗要用**同一個瀏覽器**開，不能一個 Chrome 一個 Edge，也不能用無痕視窗。

## GM：開團步驟

1. **放地圖**：點左上的「地圖設定」，上傳地圖圖片。太大的圖會自動縮小，不用先處理。一開始整張地圖都蓋著迷霧。
2. **擦開迷霧**：用右下角的按鈕切換：
   - 青色是「擦霧」（打開），灰色是「補霧」（蓋回去）。
   - 「筆刷」用畫的，「矩形」拉一個方框，「移動」則是拖動地圖而不會畫到。
   - 滑鼠滾輪或雙指可以縮放。工具列還有「全開迷霧」和「重新蓋上迷霧」。
3. **對格線**（可省略）：「格線設定」可以疊上方格或六角格，調整大小與位置對齊地圖。
4. **放棋子**：「Token 設定」可以上傳角色或怪物圖片當棋子，調整大小、形狀。
5. **先攻**：在先攻面板加入角色與敵人，把名字**拖到地圖上**就會變成紅色（敵）或綠色（友）的文字棋子。HP 只有 GM 看得到。
6. **讓玩家加入**：按「玩家 QR Code」，玩家用手機相機掃描即可。

## 玩家能做什麼

- 看到 GM 擦開的地圖，縮放、拖動畫面。
- 移動、調整**沒有上鎖**的棋子，也可以上傳自己的角色圖片。
- 擲骰，結果 GM 和其他人都看得到。
- 「地圖調整」可以調亮度、對比，只影響自己的畫面。

## 小提醒

- **棋子上鎖**：GM 放的棋子預設上鎖（🔒），玩家拖不動；想讓玩家自己移動，在「Token 設定」按一下解鎖。也有「全部鎖定／全部解鎖」。
- **重新整理不會遺失**：地圖、迷霧和棋子會記在瀏覽器裡，關掉再開還在。網路斷掉時畫面不動，恢復後會自動補上。
- **右下角的小圓點**是連線狀態。綠色代表正常；紅色時看旁邊的說明，最常見的原因是房間名稱長度不對。
- **團後清理**：「地圖設定」裡可以清除目前房間的資料。

## 沒有網路時（區域網路模式）

需要一台 Windows 筆電當 GM，並事先在有網路時安裝 [Node.js](https://nodejs.org/)（選 LTS 版）。

1. 下載這個專案，在資料夾裡按兩下 `start-lan-server.bat`。第一次會自動下載需要的東西。
2. Windows 問要不要允許網路存取時，勾「私人網路」並按允許。
3. 用視窗裡顯示的網址打開 GM 畫面，玩家連同一個 Wi-Fi 或手機熱點後掃 QR Code。
4. 團務期間別讓筆電睡眠，也不要關掉那個黑色視窗。

連不上或其他細節請看[技術文件](docs/TECHNICAL.md)。
